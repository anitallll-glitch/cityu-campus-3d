# 城大漫游 · CityUHK 3D

可在浏览器里以主人公视角探索的香港城市大学三维校园示意模型。

## 操作

- 点击「进入校园漫游」启动第一人称探索。
- WASD / 方向键行走，鼠标环顾，Shift 加速，Esc 释放鼠标。
- 支持第三人称、俯瞰视角、地标传送和位置小地图。
- 触屏使用方向按钮和拖动转向。

## 使用

index.html 是完整独立文件，包含全部 3D 渲染依赖，可在现代浏览器里直接打开。GitHub Pages 可以从 main 分支根目录发布，无需构建或安装依赖。

## 模型范围

建筑名称和校园区域参考[官方校园指南](https://www.cityu.edu.hk/cdo/download/CampusDirectory.pdf)。建筑几何、位置、距离与高度均经简化；仅为探索用示意模型，不适合实地导航。真实室内空间与楼层尚未复刻，可漫游室外及杨建文学术楼示意庭院。
